**How it works**
- **The screen** shows 3 large words: the previous word, the current word in the centre, and the next word. With "आज हमारी छुट्टी" the cursor sits on हमारी and moves along as you type. Correct letters turn green, wrong ones red, and after each word a "Space" tag shows. The **+ / −** buttons on the right change the letter size.
- **Kruti Dev typing:** the app compares your keys directly with Kruti Dev characters. You can paste ordinary Unicode Hindi and it converts it automatically, or paste text that is already in Kruti Dev. Conversions I checked include कार्यक्रम → dk;ZØe, राष्ट्र → jk"Vª, पूर्ति → iwfrZ and ब्राह्मण → czkã.k.
- **Special characters** such as ँ (Alt+0161) and the ट्र stroke (Alt+0170): hold Alt, type the number, release Alt. The app reads the code itself, so it works with a keyboard connected to the phone. **Tab** can also insert the next Alt-code character, and you can switch that off for exam practice.
- **Difficult keys:** it tracks your mistakes and how long each key takes you. **F7** shows the report and your past results. **F8** builds a practice set of words that contain your weakest keys.
- **Two modes:** practice mode stops on a mistake; exam mode carries on and lets you correct with Backspace. The timer starts on your first key. Results show net and gross speed (5 keystrokes = 1 word), accuracy, and your wrong words.

**Shortcuts**

| Key | What it does |
|---|---|
| F1 | Settings: paste from clipboard, open a .txt file, sample passages, time limit, mode |
| F2 | Back to typing |
| F3 | Hint strip: which key to press for the next letter, plus the whole word's key sequence |
| F4 | Keyboard map with the next key highlighted |
| F5 | Restart |
| F6 | Pause |
| F7 | Difficult-key report |
| F8 | Practice set |
| F9 / F10 | Smaller / larger letters |
| F11 | Fullscreen with landscape lock |
| F12 | Dark / light theme |
| Esc | Close a panel or pause |
| Ctrl+Enter | Start the passage (in Settings) |
| Ctrl+1 … Ctrl+0 | Same as F1–F10, for keyboards without F-keys |

There is also a "सरल रूप" (simple form) option for fewer Alt codes, for example त्त typed as Rr. It's off by default so practice matches standard exam typing.
